# The Code Magazine

A magazine-style article page about the basics of HTML, with author details, related posts and links to companion pages on Flexbox and CSS Grid.

**Live demo:** [the-mini-blog.netlify.app](https://the-mini-blog.netlify.app/)

![The Code Magazine](https://raw.githubusercontent.com/pokurumohanendra/My-Portfolio/main/public/projects/the-code-magazine.jpg)

## Pages

| File | Content |
|------|---------|
| `index.html` | "The Basic Language of the Web: HTML" article |
| `BLOG.html` | Blog page |
| `CONTACT.html` | Contact page |
| `flexbox.html` | Flexbox page |
| `css-grid.html` | CSS Grid page |

## Tech stack

HTML5 and CSS3. No build step or dependencies.

## Getting started

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## About

Built as a learning project to practise semantic HTML, page structure and CSS layout.
